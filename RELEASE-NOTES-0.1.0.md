# MyHealthData 0.1.0 for Android

MyHealthData is an offline-first personal health organizer for Android 7.0 and later.

## Included

- On-device encrypted health database
- Household profiles, measurements, medications, reminders, visits, vaccinations, and medical history
- Health Journal timelines and PDF reports
- Explicit encrypted backup and restore with a separate recovery code
- Android device-folder saving plus file-first, keyboard-safe restore
- Bluetooth workflows for supported health devices

## Data safety

- Android automatic cloud/device backup is disabled for this app.
- Use the app's encrypted backup and restore workflow when moving data to another device.
- Store the encrypted backup file and its recovery code separately.
- The app does not require Metro, a development server, or Wi-Fi to launch.
